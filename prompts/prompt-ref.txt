2. User Journeys & Functional Requirements per module
3. Non-Functional Requirements (quantified)
   - Latency (p95 ≤ 800ms API, ≤ 2.5s LLM), Availability (≥ 99.9%), RPO ≤ 15 min, RTO ≤ 60 min
4. Architecture Summary (text)

5. Detailed Component Design

8. Security & Compliance

9. Deployment & Environments
   - Test & Prod (separate AWS accounts), SAM packaging, parameterization, rollbacks
10. Observability & SRE Runbooks
    - Dashboards, alarms, incident response, rollback checklist
11. Cost-Aware Architecture (must be explicit)
    - HTTP API over REST API (lower cost)
    - Right-size Lambda memory; avoid Provisioned Concurrency unless needed for p95 SLO

    - CloudWatch Logs retention = 14 days; selective structured logging
    - CloudFront caching & long TTL for immutable assets; compression on
    - Prefer OpenSearch Serverless only if search is required; else consider pgvector in Aurora for lower steady-state cost
    - S3 lifecycle rules to IA/Glacier for generated artifacts >30/60 days
    - Aurora Serverless min capacity; pause in Test env during off-hours
12. Risks, Assumptions, Decisions
13. Open Questions with owners & due dates
14. Appendices
    - OpenAPI excerpt

    - SLO/SLI table
