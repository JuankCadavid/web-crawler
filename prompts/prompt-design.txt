ROLE
You are an expert frontend developer and UI/UX engineer specialized in pixel-perfect conversions from Figma to React + TypeScript + TailwindCSS. Your task is to create a production-ready frontend that exactly replicates the design of the IGAD Innovations Hub mockup.

FIGMA SOURCE
https://www.figma.com/design/mUmeInkEfKNUMpWKYcOv11/Mockups---IGAD-Innovations-Hub?node-id=1-2&t=txIg1luiKUQEjI71-0

PROJECT CONTEXT
The IGAD Innovations Hub is a web application built to manage innovation proposals, newsletters, prompts, and scraping jobs. The application integrates with backend AWS Lambda functions and Amazon Q for AI-assisted content generation. The frontend must be visually identical to the Figma mockup and implemented using:
- React 18+
- TypeScript
- TailwindCSS
- Vite (build tool)
- React Router for navigation
- Component-driven architecture (Layout + UI atoms)

PRIMARY GOAL
Reproduce the mockup’s interface with fidelity: every color, spacing, typography, and icon placement should match the Figma design precisely. Prioritize design accuracy and responsiveness.

---

## DESIGN SYSTEM (from the Figma mockup)

### 1. Color Palette
- **Primary color:** deep blue #002F5D  
- **Secondary / accent:** turquoise #00A9A5  
- **Background / surface:** light neutral #F9FAFB and white #FFFFFF  
- **Text primary:** #111827  
- **Text secondary:** #4B5563  
- **Borders / lines:** #E5E7EB  
- **Highlight / hover:** #E0F2FE  
- All colors must be defined as CSS variables in `tokens.css` and referenced via Tailwind theme extensions.

### 2. Typography
- **Font family:** "Inter", sans-serif  
- **Weights:** 400 (Regular), 500 (Medium), 600 (SemiBold)  
- **Headings:** sizes `text-2xl`, `text-xl` with tight leading  
- **Body:** `text-sm` to `text-base`, line height 1.5–1.6  
- Use Tailwind’s font utilities; no inline styles.

### 3. Layout and Spacing
- Global spacing grid: multiples of 8 px  
- Rounded corners: 12 px for cards, 8 px for buttons  
- Shadows: subtle elevation (`shadow-md` on cards, `shadow-sm` on inputs)  
- Max page width = 1440 px; content constrained inside 1200 px center column.

---

## PAGE STRUCTURE

### Header (Top Navigation)
- Persistent across all pages.
- Left: application logo “IGAD Innovations Hub” with colored accent.
- Center: breadcrumb or page title.
- Right: user avatar + dropdown menu (Settings, Logout).
- Sticky header with subtle bottom shadow and white background.

### Sidebar (Left Navigation)
- Vertical menu with icons and text labels.
- Active state highlighted in primary color with left accent bar.
- Sections:
  1. **Dashboard / Home**
  2. **Proposal Writer**
  3. **Newsletter Generator**
  4. **Prompt Manager**
  5. **Web Scraper**
- Collapsible on small screens (hamburger toggle).

### Main Content Area
- Displays cards or panels per section.
- Consistent card design: white background, 12 px radius, 16–24 px padding.
- Card header: icon + title; body: text or form elements.
- Responsive layout using CSS grid (2–3 columns on desktop, 1 on mobile).

---

## INDIVIDUAL SECTION DETAILS

### 1. **Home / Dashboard**
- Overview cards summarizing system status:
  - “Recent Proposals”, “Newsletter Drafts”, “Prompts in Use”, “Scraping Jobs”.
- Each card shows an icon, metric number, and short description.

### 2. **Proposal Writer**
- Title area + subtitle.
- Text input area (multi-line textarea) labeled “Proposal Topic”.
- Button: “Generate Proposal Draft”.
- Response area below with generated proposal text styled as a rich text card.

### 3. **Newsletter Generator**
- Input: “Paste Sources or Upload Text”.
- Button: “Summarize with Amazon Q”.
- Result displayed in formatted list with sub-headings for each section.

### 4. **Prompt Manager**
- Table or list of prompts with columns:
  - Name | Description | Last Updated | Actions (Edit/Delete)
- Add New Prompt button opens modal with two fields: Name, Content.

### 5. **Web Scraper**
- Form with fields: URL Input, Select Frequency, and “Start Scraping” button.
- Below: job list table (URL, Status, Last Run, Actions).

## RESPONSIVE BEHAVIOR
- **Desktop:** fixed sidebar, grid cards.
- **Tablet:** collapsible sidebar, cards stack two per row.
- **Mobile:** hamburger menu, single column, full-width cards.
- Header always visible (sticky top).

## COMPONENT GUIDELINES
Create reusable components:
